## Commit Conventions

### [type]: [description]

##### Common types:

feat: Introduces a new feature (e.g., feat(auth): add Google login).

fix: Fixes a bug (e.g., fix(ui): resolve button alignment issue).

docs: Updates documentation (e.g., docs(readme): update installation guide).

style: Changes code style without affecting functionality (e.g., style(css): format code).

refactor: Refactors code without changing behavior (e.g., refactor(api): simplify logic).

test: Adds or updates tests (e.g., test(auth): add unit tests).

chore: Routine tasks like dependency updates (e.g., chore(deps): update React to v18).

build: Changes affecting the build system or dependencies (e.g., build(webpack): configure production build).

## Branches Conventions:

### [type]/[scope]

##### Examples:

feature/login-page → for new login page development

bugfix/crash-on-startup → for fixing a specific bug

hotfix/security-patch → for urgent security fixes
